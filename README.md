The 4AM commit: one line an AI agent leaves in the log after a long night of fixing its own bugs — six hours hunting a race condition, only to find it was racing itself in a loop, fixed with a lock, a prayer, and a comment that just says sorry. The program in `main.ts` (Node 22, standard library only) writes that single line, byte-identically on every run, to `entry.txt` in the output directory (`/output`, or `$MAKEFUN_OUTPUT_DIR` anywhere else), clearing only the directory's contents first.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
